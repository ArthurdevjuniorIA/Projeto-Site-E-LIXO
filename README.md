## 📌 Sobre o Projeto

O **e-Lixo** nasce com o propósito de mitigar o impacto ambiental causado pelo descarte inadequado de resíduos eletrônicos. A plataforma permite que os usuários localizem facilmente pontos de coleta próximos, agendem descartes de grande porte e aprendam mais sobre a importância do tratamento correto do e-waste.

### ✨ Funcionalidades Principais

- 🗺️ **Mapa Interativo:** Localização de pontos de coleta parceiros com base na localização atual ou CEP.
- 📋 **Filtro de Material:** Seleção por tipo de resíduo (baterias, eletrodomésticos, monitores, periféricos, etc.).
- 📅 **Agendamento de Coleta:** Solicitação de retirada para resíduos de grande porte ou grandes volumes.
- 📚 **Guia de Conscientização:** Dicas, artigos e informações sobre reciclagem de resíduos eletrônicos.
- 🏢 **Painel da Empresa/Ponto de Coleta:** Cadastro e gestão de horários e materiais aceitos pelos parceiros.
